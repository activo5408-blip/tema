# Negro Elegante — Rainmeter

Skin compacto y oscuro para Rainmeter en Windows 10.

## Incluye
- Uso de CPU.
- Memoria RAM utilizada.
- Velocidad de descarga y subida.
- Porcentaje de espacio usado en las unidades C:, D:, E:, F:, G: y H:.

## Instalación
1. Instala Rainmeter desde https://www.rainmeter.net/
2. Descarga `NegroElegante.ini` desde este repositorio.
3. Crea la carpeta `NegroElegante` dentro de `Documentos\Rainmeter\Skins\`.
4. Guarda el archivo como `NegroElegante.ini` dentro de esa carpeta.
5. Abre Rainmeter y pulsa **Refresh all**.
6. En Manage Rainmeter, selecciona `NegroElegante\NegroElegante.ini` y pulsa **Load**.

## Personalización
Las unidades se configuran de forma estática. Si tu PC no tiene alguna letra, puedes quitar su bloque; si tienes otras unidades, copia un bloque y cambia `Drive=C:` por la letra correspondiente.

## Temperaturas
Esta versión no muestra temperaturas todavía. Para añadir temperaturas fiables de CPU/GPU hace falta integrar sensores, por ejemplo mediante HWiNFO y su plugin/medidas compatibles con Rainmeter.

No modifica ni escribe en los discos; únicamente consulta métricas del sistema y espacio disponible.
