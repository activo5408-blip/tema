# DotCom — Rainmeter

Skin compacto y oscuro para Rainmeter en Windows 10.

## Instalación con doble clic
1. Si no tienes Rainmeter, instálalo desde https://www.rainmeter.net/.
2. Pulsa **Code → Download ZIP** en este repositorio: https://github.com/activo5408-blip/tema
3. Extrae el ZIP en una carpeta.
4. Haz doble clic en **Instalar.bat** y espera a que termine. El instalador descarga el archivo INI, lo copia a la carpeta de skins y, si encuentra Rainmeter, carga el panel automáticamente.

Si Windows muestra una advertencia, asegúrate de que descargaste los archivos de este repositorio antes de permitir la ejecución.

## Incluye
- Uso de CPU.
- Memoria RAM utilizada.
- Velocidad de descarga y subida.
- Porcentaje de espacio usado en las unidades C:, D:, E:, F:, G: y H:.

## Personalización
Las unidades se configuran de forma estática. Si tu PC no tiene alguna letra, puedes quitar su bloque; si tienes otras unidades, copia un bloque y cambia `Drive=C:` por la letra correspondiente.

## Temperaturas
Esta versión todavía no muestra temperaturas de CPU/GPU; requiere integrar sensores compatibles, por ejemplo mediante HWiNFO.

El tema no borra ni modifica archivos de tus discos; consulta métricas del sistema y espacio disponible.
